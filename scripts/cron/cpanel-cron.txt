## cPanel Cron Jobs

### Laravel Scheduler (every minute)

```cron
* * * * * cd /home/USERNAME/apps/client-portal/current && /usr/bin/php artisan schedule:run >> /dev/null 2>&1
```

### Daily database backup (recommended)

```cron
0 2 * * * source /home/USERNAME/apps/client-portal/shared/.env && /home/USERNAME/apps/client-portal/current/scripts/backup/db-backup.sh >> /home/USERNAME/backups/db/backup.log 2>&1
```

### Weekly “full” backup (shared storage + DB dump)

```cron
30 2 * * 0 source /home/USERNAME/apps/client-portal/shared/.env && /home/USERNAME/apps/client-portal/current/scripts/backup/full-backup.sh >> /home/USERNAME/backups/full/backup.log 2>&1
```

### Retention pruning (daily)

```cron
15 3 * * * RETENTION_DAYS=30 TARGET_DIR=/home/USERNAME/backups /home/USERNAME/apps/client-portal/current/scripts/backup/retention.sh >> /home/USERNAME/backups/retention.log 2>&1
```

### Optional: queue worker via cron (NOT recommended vs Supervisor)

```cron
* * * * * cd /home/USERNAME/apps/client-portal/current && /usr/bin/php artisan queue:work --stop-when-empty --sleep=1 --tries=3 >> /dev/null 2>&1
```
