# Admin User Manual

## Access
- Admin dashboard: `/admin/dashboard`
- Reports: `/admin/reports`
- System settings: `/admin/settings`
- Webhooks: `/admin/settings/webhooks`
- Automation: `/admin/automation`
- API docs: `/api/documentation`

## Common tasks

### Manage clients
- Create/edit client records
- Create users and assign roles (admin/staff/client)

### Requests
- Review new requests
- Assign requests to staff
- Update status and add comments

### Invoices + payments
- Create invoices and line items
- Mark as sent/paid (as applicable)
- Review payment activity (Stripe)

### Storage integrations
- Connect S3/Dropbox/Google Drive
- Review sync history and usage

### Webhooks
- Register endpoints per client and event type
- Test endpoints and review delivery history

### Automation
- Build rules: Trigger → Conditions → Actions
- Use dry-run testing with sample payload
- Review execution logs for failures
